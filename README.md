# Afterburner-Online
Аркадные гонки с RPG и кастомизацией. Разные машины с уникальными характеристиками и прокачкой (детали из кейсов). Режимы: гонки с друзьями, онлайн мультиплеер, боты. Разнообразные трассы, скины и кейсы. Оригинальный саундтрек, локализация (русский, английский). Для любителей аркадных гонок, кастомизации и мультиплеера.
